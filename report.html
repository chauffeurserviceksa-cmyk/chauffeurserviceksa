Chauffeur Service KSA – Project Report

📖 Overview

This repository contains the web‑application for Chauffeur Service KSA, a luxury private‑driver platform targeting Saudi Arabia. The project is built with Next.js 16.2.2 (using Turbopack) and follows a modern app‑router architecture.

🔧 Backend Features Implemented

  • Admin Dashboard – UI under /admin secured by a simple cookie‑based auth middleware.
  • Login Page – Email/password against env‑variables.
  • Booking Form – Client‑side validation; stores data in data/bookings.json.
  • Quote Request Form – Similar flow, data saved in data/quotes.json.
  • Invoice / Receipt Generation – Uses pdf-lib to produce PDFs from a HTML letterhead template.
  • Email Automation – nodemailer endpoint sends templated emails for quotes and invoices.
  • Data Validation – All API routes validate payloads with zod.
